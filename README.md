# Todolist

Projeto desenvolvido durante o curso introdutório de Java com Spring Boot da Rocketseat.

## Sobre o projeto

O projeto consiste no desenvolvimento de uma aplicação para gerenciamento de tarefas, com o objetivo de praticar conceitos de desenvolvimento de APIs utilizando Java e Spring Boot.

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Maven
- Git
- GitHub

## Objetivos de aprendizado

- Desenvolver uma API REST com Spring Boot
- Praticar conceitos de Java
- Trabalhar com Maven
- Utilizar Git e GitHub para versionamento
- Compreender a estrutura de uma aplicação Spring Boot

Em desenvolvimento.
